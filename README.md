# FitLog

FitLog is a workout planning app that helps you explore a library of lifts, build a plan for today, and save workouts you want to revisit later.

## 🚀 Technologies

- **Next.js 16** with the App Router
- **React 19** and **TypeScript**
- **Tailwind CSS 4** and **DaisyUI**
- **React Icons**
- **React Toastify**
- **FitLog Workout API**

## ✨ Features

1. **Explore the Workout Library**  
   Browse twelve lifts covering major muscle groups.

2. **View Workout Details**  
   Check each workout's duration, calories burned, rating, equipment, and instructions.

3. **Build Today's Plan**  
   Add workouts to today's dedicated plan and manage your workout list.

4. **Save Workouts for Later**  
   Save workouts you want to revisit and easily move them between your saved list and today's plan.

5. **Review and Organize Your Plan**  
   View exercise, time, and calorie totals and organize workouts by duration, calories, or rating.
